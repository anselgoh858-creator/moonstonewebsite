# Moonstone PARK Day prototypes

Run `npm install`, then `npm run dev`. Open `/` for the market and `/ar-trail.html` for the walking trail. Use `npm run build` for production.

The walking trail is a visual simulation: it does not access AR, camera, GPS, accounts, QR validation, payments or a backend. Completed hotspot IDs are stored locally under `moonstone-ar-progress-v1`. **Complete Trail Demo** unlocks the ending; **Reset** clears progress.

Replace research placeholders and quiz copy in `src/trail-data.ts` with verified, cited, permission-cleared material. Replace the building placeholders in `src/ar-main.tsx` with approved images and descriptive alt text.
